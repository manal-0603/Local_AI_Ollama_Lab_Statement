# Local AI with Ollama — Practical Lab

Practical lab *Running and Developing Local AI Applications* (PhD programme, FSTT Tangier): running open-weight LLMs locally with Ollama and building Python applications on top of its REST API.

- `Local_AI_Ollama_Lab_Statement.ipynb` — the lab statement (original notebook).
- `Local_AI_Ollama_Lab_Solution.ipynb` — the executed notebook with all outputs, measurements and written answers.
- `LocalAI_Lab/` — the deliverable: sources of the final project (Flask web app, console chatbot, mini-RAG, benchmark), course documents, screenshots and the report (`report.pdf`). See `LocalAI_Lab/README.md` for installation and usage.

Models used: `qwen3.5:2b-q4_K_M`, `gemma3:1b`, `nomic-embed-text` (Ollama 0.40.12, Apple M2 Pro 16 GB).
